Esta tool permite crear planes de desarrollo estructurados (grupos de tareas) en Task Manager, ya sea vacíos o basados en plantillas, y gestiona si es un plan compartido (oneForAll) o individual (onePerUser). La tool procesa el payload de forma interna para forzar el flag de sistema (label: "ai-made"), valida el tipo de plan y homogeneiza la prioridad de todas las tareas a 20 para mitigar errores de validación por volumen en el backend. Parámetros allocation_type (str): Modalidad de distribución del plan. Determina el endpoint a utilizar y NO se envía en el body. Valores: "oneForAll": Un único plan compartido para todo el grupo de usuarios. "onePerUser": Un plan independiente y dedicado para cada usuario de la lista. payload (dict): Diccionario complejo con los datos del plan. Debe contener las siguientes llaves principales: name (str): Nombre del plan de desarrollo. description (str | None): Descripción general del plan (soporta HTML básico). endDate (str | None): Fecha límite general del plan en formato ISO 8601. label (str): Etiqueta del sistema. La tool la forzará automáticamente a "ai-made". type (str): Tipo de flujo. Mapear como "unordered" (Independientes) o "ordered" (Secuenciales). assignedUsers (list[int]): IDs numéricos de los usuarios asignados al plan. tasks (list[dict]): Lista de objetos de tareas en orden estricto de lectura. Cada diccionario interno contiene: title (str): Título de la tarea. description (str | None): Detalle explicativo de la tarea. priority (int): Prioridad. La tool la forzará automáticamente a 20. endDate (str): Fecha de vencimiento de la tarea en formato ISO 8601. assigneeId (int, opcional): ID del usuario responsable de esta tarea específica. assigneeRole (str, opcional): Rol del responsable de la tarea (ej. "collaborator").
